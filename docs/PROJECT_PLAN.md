# Build order

1. Install Python + VS Code.
2. Create virtual environment.
3. Install requirements.
4. Run app.py in DEMO mode.
5. Verify webcam.
6. Obtain a properly licensed waste dataset.
7. Put it into YOLO format.
8. Train the custom model.
9. Copy best.pt to models/best.pt.
10. Run app.py again.
11. Test plastic/paper/metal/glass/organic.
12. Record real metrics and screenshots.
13. Prepare report, PPT and viva.
